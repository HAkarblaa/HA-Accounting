تحديث: شاشة اختيار الهندسة أو المعالجات

ما الذي يتغير؟
- عند دخول حساب اختصاصه «هندسة ومقاولات»، تظهر مباشرة صفحة فيها مربعان واضحان: «قسم الهندسة» و«قسم المعالجات».
- اختيار قسم الهندسة يفتح مشاريع وبيوت الهندسة.
- اختيار قسم المعالجات يفتح لوحة المبيعات والمشتريات والمخزون والزبائن والمجهزين والديون والتقارير.
- يوجد رجوع إلى شاشة اختيار القسم من داخل القسمين.
- تبقى بيانات وأرباح القسمين منفصلة. بقية الاختصاصات لا تتغير.

طريقة التركيب:
1. فك ضغط الملف.
2. ارفع الملفات الثلاثة إلى جذر مستودع HA-Accounting في GitHub واستبدل النسخ الموجودة: index.html و auth-client.js و service-worker.js.
3. انتظر اكتمال GitHub Pages، ثم افتح الموقع وحدّثه تحديثاً إجبارياً بـ Ctrl+F5. على الهاتف أغلق الصفحة وافتحها من جديد.

ملاحظة: يظهر اختيار القسم للمستخدم الذي عيّن الأدمن اختصاصه «هندسة ومقاولات» بعد تسجيل الدخول.
