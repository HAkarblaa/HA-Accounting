تحديث قسم الهندسة والمقاولات

المحتويات:
- index.html: يضيف قائمة المبيعات والمشتريات والزبائن والمجهزين والمخزن والديون والقيود والأقساط ولوحة التحكم والتقرير اليومي.
- service-worker.js: يحدّث رقم نسخة التخزين المؤقت حتى تصل الواجهة الجديدة للموبايل والأوفلاين.

طريقة التركيب:
1. فك الضغط.
2. ارفع index.html وservice-worker.js إلى المجلد الرئيسي للموقع، واستبدل النسختين الموجودتين.
3. انتظر اكتمال نشر GitHub Pages، ثم حدّث الصفحة. على الهاتف أغلق التطبيق وافتحه بعد اتصال الإنترنت حتى ينزل التحديث.

البيانات تبقى ضمن حساب المستخدم؛ والقوائم الجديدة تظهر لحساب اختصاص الهندسة فقط. لا يحتاج هذا التعديل إلى SQL إضافي.
