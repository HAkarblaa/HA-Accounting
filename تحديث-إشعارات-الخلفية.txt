تحديث إشعارات الأقساط المتأخرة — HA محاسبة

هذا التحديث يجعل Supabase يفحص الاستحقاقات كل ساعة ويرسل إشعاراً حتى لو الموقع مغلق. يرسل تنبيهاً مرة واحدة لكل قسط/فاتورة متأخرة، إلى الجهاز المرتبط بالحساب.

الملفات التي ترفعها إلى GitHub Pages (استبدل النسخ الحالية):
- index.html
- auth-client.js
- service-worker.js
اترك supabase-config.js كما هو. لا ترفع ملفات SQL إلى مستودع الموقع.

الخطوات في Supabase:
1. افتح Edge Functions وأنشئ دالة باسم accounting-push. الصق محتوى supabase/functions/accounting-push/index.ts ثم انشرها.
2. افتح إعدادات الدالة، وأوقف Verify JWT لهذه الدالة فقط، ثم أعد النشر إذا طلب منك. الدالة تتحقق من جلسة المستخدم بنفسها للعمليات العادية، وتتحقق من سر خاص لاستدعاء الفحص المجدول.
3. من Settings > Edge Function Secrets أضف القيم الموجودة بملف HA-Accounting-Push-Secrets.txt كل قيمة مقابل اسمها. لا تضع هذا الملف في GitHub. Supabase يقرأ القيم الجديدة دون نشر جديد.
4. افتح SQL Editor والصق محتوى supabase/setup.sql كاملاً وشغّله. هذا ينشئ جداول اشتراكات الإشعارات وسجل الإشعارات.
5. افتح ملف push-scheduler.sql على جهازك، استبدل النص PASTE_HA_PUSH_CRON_SECRET_HERE بقيمة HA_PUSH_CRON_SECRET من ملف الأسرار (احذف الأحرف المخفية حول كلمة PASTE إن ظهرت)، ثم الصق SQL في SQL Editor وشغّله. هذا يضيف الفحص كل ساعة.
6. ارفع ملفات GitHub الثلاثة أعلاه وانتظر تحديث الموقع، ثم سجّل دخولك وافتح الأقساط والاستحقاقات واضغط «تفعيل إشعارات الخلفية» واسمح بإشعارات المتصفح.

لتجربة الفحص فوراً:
- بعد تشغيل SQL المجدول، افتح Supabase > Edge Functions > accounting-push > Invoke، وأرسل JSON: {"action":"run"} مع ترويسة x-ha-cron-secret بقيمتها الخاصة. أو انتظر الفحص الدوري. لا ترسل السر في محادثة أو تنشره.

ملاحظات:
- يحتاج رابط HTTPS والإنترنت وإذن الإشعارات. في بعض هواتف iPhone يلزم تثبيت الموقع إلى الشاشة الرئيسية قبل الاشتراك بالإشعارات.
- الإشعار يصل فقط إلى جهاز الحساب المرتبط؛ إذا فك الأدمن ربط الجهاز، سجل الدخول من الجهاز الجديد وفعّل الإشعار هناك.
- فحص النظام كل ساعة؛ قد يتأخر التنبيه إلى ساعة بعد موعد الاستحقاق.
- هذا Web Push عبر المتصفح؛ عند تحويله لاحقاً إلى تطبيق أصلي قد نحتاج ربط إشعارات Android/iPhone الأصلية.
- لا ترفع ملفات SQL أو ملف الأسرار إلى مستودع GitHub العام.
