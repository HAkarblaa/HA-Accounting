تحديث صلاحيات الأقسام حسب نشاط المشترك

الأنشطة المتاحة:
- مطعم / مقهى: الكاشير والمبيعات والمشتريات والمخزون والزبائن والتقارير وطلبات الطاولات.
- جملة: أقسام البيع والشراء والمخزون والذمم والتقارير والحسابات اللازمة للجملة.
- أسواق / تجزئة: الكاشير والمبيعات والمشتريات والمخزون والصندوق والزبائن والتقارير.
- نشاط آخر: كل الأقسام.

يشمل التعيين الحسابات الحالية والجديدة. الحسابات الحالية تُحفظ مؤقتاً على «كل الأقسام» حتى يحدد الأدمن نشاطها.

خطوات التطبيق:
1. في Supabase SQL Editor شغّل activity-modules-setup.sql مرة واحدة.
2. حدّث Edge Function الموجودة باسم manage-subscribers باستبدال مصدرها بملف manage-subscribers-index.ts، ثم أعد نشرها بالاسم نفسه. رفع ملف TS إلى GitHub وحده لا ينشر الدالة.
3. ارفع إلى جذر مستودع الموقع: index.html و auth-client.js و service-worker.js و restaurant-orders.html، ووافق على استبدال الملفات الموجودة.
4. إذا لم تكن قد شغّلت إعداد طلبات المطعم سابقاً، شغّل restaurant-orders-setup.sql مرة واحدة. إذا شغّلته قبل، لا تعِد تشغيله.
5. بعد النشر، افتح «إدارة الحسابات». لكل مشترك اختر نوع النشاط واضغط «حفظ النشاط». وللحساب الجديد اختر النشاط من نموذج إنشاء الحساب.
6. يحدّث المشترك الصفحة بعد النشر، ويحتاج اتصالاً بالإنترنت حتى تُجلب الصلاحية الجديدة. بعدها تُحفظ للعمل أوفلاين على جهازه.

مهم: تحديث قاعدة البيانات والدالة مطلوب حتى تعمل صلاحيات المشتركين الحاليين والجدد. لا ترفع service-role key إلى GitHub؛ الدالة تستخدم إعدادات Supabase السرية الموجودة لديها.
