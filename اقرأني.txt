تحديث HA محاسبة — البيع والشراء بالكارتون والمفرد

أضيفت تفاصيل التغليف والتسعير لكل صنف:
- عدد المفردات الموجودة داخل الكارتون.
- سعر شراء الكارتون.
- سعر بيع الكارتون بالجملة.
- سعر بيع المفرد وكلفة المفرد.
- معاينة ربح المفرد وربح الكارتون.
- عرض بيانات الكارتون في بطاقة المخزون.
- اختيار الوحدة (مفرد أو كارتون) في فواتير المبيعات والمشتريات.
- تحويل الكمية إلى مفردات عند تحديث المخزون وحساب تكلفة المبيعات.
- حفظ الوحدة والكمية في تفاصيل الفاتورة وتصدير CSV.

طريقة الرفع إلى GitHub Pages:
1. فك ضغط هذا الملف.
2. ارفع index.html وservice-worker.js وauth-client.js إلى جذر مستودع HA-Accounting.
3. وافق على استبدال الملفات القديمة ثم اضغط Commit changes.
4. انتظر انتهاء نشر GitHub Pages، ثم افتح الموقع مع الإنترنت أو حدّث الصفحة.

طريقة الاستخدام:
1. افتح إدارة المخزون ثم إضافة منتج.
2. أدخل وحدة المفرد، وعدد القطع داخل الكارتون، وسعر الشراء وسعر البيع بالجملة للكارتون، وسعر بيع المفرد.
3. في فاتورة بيع أو شراء اختر الصنف، ثم حدد «كارتون» أو «مفرد».
4. عند حفظ الفاتورة، يحوّل البرنامج عدد الكراتين إلى عدد المفردات لتحديث رصيد المخزون.

ملاحظة: رصيد المخزون يُحفظ بوحدة المفرد دائماً، لذلك اكتب الكمية الافتتاحية وعدّ الجرد بوحدة المفرد. عند شراء كارتون، اختر «كارتون» في بند الفاتورة وسيضيف البرنامج محتواه إلى الرصيد.
