إضافة حذف الحساب للأدمن الرئيسي

محتويات التحديث:
- auth-client.js: يضيف زر «حذف الحساب» داخل إدارة الحسابات، مع نافذة تأكيد قبل الحذف.
- manage-subscribers-index.ts: يضيف إجراء حذف آمن عبر Edge Function؛ يمنع حذف الأدمن الرئيسي أو الحساب الحالي، ويحذف تسجيل دخول المشترك واشتراكه وبياناته السحابية.

التثبيت:
1. استبدل auth-client.js في جذر مستودع GitHub بهذا الملف، ثم انتظر نشر الموقع.
2. افتح Supabase > Edge Functions > manage-subscribers، واستبدل كود الدالة بمحتوى manage-subscribers-index.ts ثم اضغط Deploy.
   إذا تنشر عبر Supabase CLI، ضع الملف في: supabase/functions/manage-subscribers/index.ts ثم انشر الدالة.
3. حدّث الموقع تحديثاً إجبارياً (Ctrl+F5).

ملاحظة: حذف الحساب نهائي ولا يمكن التراجع عنه. تظهر نافذة تأكيد قبل التنفيذ. إذا كانت للحساب ملفات مرفوعة في Supabase Storage فقد يرفض Supabase الحذف إلى أن تُحذف ملفاته أولاً.
