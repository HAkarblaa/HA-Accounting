تحديث تسجيل الدخول والمزامنة لموقع HA محاسبة

ملفات الموقع التي تستبدلها داخل مستودع GitHub Pages:
- index.html
- service-worker.js
- auth-client.js (ملف جديد)
- supabase-config.js (ملف جديد، يحتوي رابط المشروع والمفتاح العام فقط)

الخطوات:
1) ارفع الملفات الأربعة أعلاه إلى جذر مستودع HA-Accounting واستبدل الملفات الموجودة عند طلب ذلك.
2) في Supabase افتح SQL Editor وشغّل ملف supabase/setup.sql كاملاً مرة ثانية. هذه النسخة تضيف حماية قاعدة البيانات من الحسابات الموقوفة أو المنتهية، وتحافظ على الأدمن.
3) انشر Edge Function باسم manage-subscribers من مجلد supabase/functions/manage-subscribers. هذه الدالة هي التي تمكّن الأدمن من إنشاء حسابات المشتركين وإيقافها. إعداد verify_jwt موجود في supabase/config.toml.
4) بعد اكتمال نشر GitHub Pages، افتح الموقع وسجّل دخول الأدمن بالبريد وكلمة المرور اللذين أنشأت بهما مستخدم Supabase. المشترك يسجل بالمعرّف وكلمة المرور التي أنشأها الأدمن.
5) من زر «إدارة المشتركين» أنشئ حساباً تجريبياً، ثم اختبر الدخول به من نافذة خاصة قبل إرسال بياناته لصاحبه.

مهم:
- المفتاح الموجود في supabase-config.js هو Publishable key عام ومناسب للمتصفح.
- لا تضع sb_secret أو service_role أو كلمة مرور قاعدة البيانات في GitHub أو ملفات الموقع، ولا ترسلها بالمحادثة. مفاتيح الخدمة تبقى ضمن إعدادات Supabase/Edge Function فقط.
- البيانات تزامن لكل مستخدم إلى مساحة محمية بسياسات RLS. يلزم إنترنت لتسجيل الدخول أول مرة؛ بعد ذلك يحفظ التطبيق محلياً ويزامن التغييرات عند رجوع الإنترنت.
- بياناتك القديمة من المتصفح تُنقل إلى مساحة الأدمن عند أول دخول إذا لم تكن مساحة سحابية موجودة. حسابات المشتركين تبدأ بمساحات مستقلة.
