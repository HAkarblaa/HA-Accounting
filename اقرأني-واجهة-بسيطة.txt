تحديث اختصاص «واجهة بسيطة»

المحتويات المطلوبة للموقع:
- index.html
- auth-client.js
- service-worker.js
- manage-subscribers/index.ts
- simple-interface-module-type.sql

محتوى الاختصاص:
- لوحة مختصرة للمبيعات والمشتريات والمخزون والديون والمصروفات.
- مخزن مبسط: أزرار واضحة لإضافة منتج وإضافة قسم، مع تعديل وحذف المنتجات والبحث بالاسم، من دون حقول باركود في الاختصاص.
- فواتير مبيعات ومشتريات متعددة المواد، واختيار الدفع نقداً أو على الحساب.
- قائمتان منفصلتان للزبائن والمجهزين.
- متابعة الأقساط والاستحقاقات (تاريخ أول استحقاق، عدد الأقساط، الدفعات المسجلة)، والمصروفات والتقارير حسب اليوم أو نطاق تاريخ. لا تظهر صفحة الديون ضمن هذا الاختصاص.
- لا يتغير سلوك بقية الاختصاصات؛ يظهر الاختصاص فقط للحساب المعيّن عليه.

لتركيب ملفات الموقع:
1. استبدل الملفات الأربعة الأولى بنظائرها في المستودع، مع وضع index.ts داخل مجلد الدالة manage-subscribers.
2. في Supabase SQL Editor شغّل ملف simple-interface-module-type.sql مرة واحدة.
3. انشر نسخة manage-subscribers/index.ts على Edge Function بالاسم نفسه، مع إعداد verify_jwt=false كما في إعداد الدالة الحالية.
4. بعد اكتمال نشر GitHub Pages، حدّث الموقع تحديثاً كاملاً. إذا بقيت النسخة القديمة امسح بيانات الموقع/الكاش أو أغلق المتصفح وافتحه.
5. من إدارة الحسابات اختر «واجهة بسيطة» للحساب المطلوب ثم احفظ النشاط.

تنبيه: SQL يحدّث قائمة أنواع النشاط المسموح بها في قاعدة البيانات، وملف Edge Function يضيف النوع إلى قائمة السماح بالدالة. لا يكفي رفع ملفات الواجهة وحدها لتعيين الاختصاص للحسابات.
