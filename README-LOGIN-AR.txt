تفعيل تسجيل الدخول — HA محاسبة

الحزمة تجعل البرنامج يفتح شاشة الدخول أولاً. لا يوجد إنشاء حساب ذاتي؛ الأدمن الرئيسي ينشئ حسابات المستخدمين من داخل البرنامج.

الإعداد مرة واحدة:
1. ارفع ملفات الحزمة إلى جذر مستودع HA-Accounting في GitHub واستبدل الملفات القديمة، ثم انتظر اكتمال GitHub Pages.
2. في Supabase افتح SQL Editor، ثم شغّل ملف setup-login.sql كاملاً.
3. في Supabase > Authentication > Settings عطّل السماح بإنشاء حسابات ذاتياً (Allow new users to sign up)، حتى تكون الحسابات من الأدمن فقط.
4. أنشئ مستخدم الأدمن الأول من Authentication > Users > Add user. استخدم بريداً بالشكل: admin@ha-accounting.invalid، وأنشئ له كلمة مرور.
5. انسخ UUID الخاص بالمستخدم من صفحة Users. في SQL Editor نفّذ هذا الاستعلام بعد وضع UUID مكانه:

   insert into public.super_admins (user_id)
   values ('UUID-هنا');

6. انشر manage-subscribers-index.ts كـ Edge Function باسم manage-subscribers. خزّن مفاتيح Supabase السرية في إعدادات الدالة فقط، ولا تضع service-role key في ملفات الموقع.
7. افتح رابط الموقع وسجّل دخول الأدمن بالمعرّف admin وكلمة المرور. من زر «إدارة الحسابات» أنشئ حسابات المشتركين.

الدخول:
- يكتب المستخدم المعرّف وكلمة المرور اللذين أعطاهما الأدمن.
- المعرّف يتحول داخلياً إلى بريد تقني في Supabase؛ لا يحتاج المستخدم إلى بريد حقيقي.
- الأدمن والمشترك يگدرون يسجلون دخول من أكثر من جهاز بالحساب نفسه. أول تسجيل دخول على كل جهاز يحتاج إنترنت. بعده يعمل البرنامج أوفلاين ويحفظ التعديلات محلياً، ثم يزامنها مع Supabase عند عودة الاتصال. البيانات التوضيحية تظهر للأدمن فقط؛ حساب المشترك يبدأ من دون بيانات أمثلة.
- تسجيل الخروج يعيد شاشة الدخول. الحساب الموقوف أو المنتهي لا يدخل عند توفر الإنترنت.

مهم:
- Supabase Publishable key الموجود في supabase-config.js مخصص للاستخدام بالمتصفح. لا تضع Secret أو service-role key في GitHub.
- للمشتركين الحاليين لا تستبدل supabase-config.js بمفاتيح مشروع آخر.
- Edge Function ملفها المصدر موجود في supabase/functions/manage-subscribers/index.ts داخل الحزمة. رفعه إلى GitHub وحده لا ينشر الدالة؛ يجب نشره في Supabase باسم manage-subscribers.
- ميزة الحسابات تعتمد على مشروع Supabase نفسه. لا تغيّر معرف المشروع أو المفتاح العام.

من شاشة الموظفين والرواتب توجد المصاريف التشغيلية المتكررة: أدخل مبلغاً يومياً أو مبلغاً شهرياً يوزعه النظام على أيام الشهر. القيد اليومي يمنع التكرار، ويمكن ترحيله كمستحق أو كمدفوع من الصندوق/المصرف ثم تسديد المستحقات.
