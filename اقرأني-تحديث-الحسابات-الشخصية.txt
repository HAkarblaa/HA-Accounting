تحديث إضافة نشاط «حسابات شخصية»

استبدل الملفات التالية في جذر مستودع GitHub:
- index.html
- auth-client.js
- service-worker.js

بعد رفعها انتظر نجاح GitHub Pages، ثم حدّث الصفحة بـ Ctrl+F5.

تم تحديث قاعدة بيانات Supabase ودالة manage-subscribers مباشرة لدعم النشاط الجديد. لا تعِد تشغيل ملف SQL ولا ترفع ملف الدالة إلى GitHub Pages.

أقسام الحسابات الشخصية: لوحة التحكم، القيود اليومية، دليل الحسابات، الأقساط والاستحقاقات، الصندوق والبنوك، الزبائن والمجهزون، التقارير المالية، والإعدادات.
