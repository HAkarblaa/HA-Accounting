تصحيح اختيار المواد في فواتير بيع وشراء المعالجات.
اسم المادة وسعرها يبدآن فارغين؛ لا يتم اختيار أول مادة بالمخزون تلقائياً.
يمكن كتابة اسم المادة الموجودة أو اختيارها من نتائج البحث.
زر إضافة مادة يضيف سطراً فارغاً، وكذلك عند إضافة مادة أثناء تعديل فاتورة.
لا يحفظ السطر غير المكتمل: أكمله أو احذفه ثم احفظ.
الفواتير القديمة تحتفظ بالمواد المسجلة فيها.
ارفع index.html و service-worker.js مع الاستبدال، وبعد النشر اضغط Ctrl+F5 والإنترنت شغال.
نجحت اختبارات DOM للاختيار والكتابة والحفظ الفارغ والتصحيح والحذف والمحافظة على البنود القديمة، وفحوص JavaScript.
