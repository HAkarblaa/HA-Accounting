إصلاح تعديل منتجات قسم المعالجات

الملفات:
- index.html
- auth-client.js
- service-worker.js

ما تم إصلاحه:
- إضافة حقل لتعديل الكمية الحالية للمنتج.
- السماح بحفظ بقية المعلومات عند بقاء الاسم كما هو، حتى لو كان الاسم مكرراً من بيانات سابقة.
- منع اختيار اسم مكرر عند تغيير الاسم إلى اسم مستخدم لمنتج آخر.
- حفظ الاسم والوحدة والكمية والكلفة وسعر البيع مع إبقاء الفواتير السابقة كما هي.

ملاحظة:
تعديل الكمية من بطاقة المنتج يغير رصيد المخزون الحالي فقط، ولا يسجل فاتورة شراء أو مصروفاً. سجّل فاتورة شراء إذا تريد توثيق الشراء والدفعات أو الدين.

التثبيت:
خذ نسخة احتياطية، فك الضغط، وارفع الملفات الثلاثة إلى جذر مستودع GitHub مع استبدال الملفات المناظرة، ثم انتظر انتهاء GitHub Pages من النشر.
