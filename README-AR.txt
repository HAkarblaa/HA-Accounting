تحديث بقاء تسجيل الدخول والواجهة والمعلومات عند انقطاع الإنترنت

طريقة التركيب
ارفع محتويات هذا الملف كاملة إلى المجلد الرئيسي للموقع مع استبدال الملفات، وحافظ على مجلد vendor ومساره.
الملفات: index.html و auth-client.js و service-worker.js و vendor/supabase-2.118.0.js.
بعد اكتمال نشر GitHub Pages افتح الموقع بالإنترنت واضغط Ctrl+F5 مرة واحدة، وانتظر اكتمال تحميل الصفحة حتى تُحفظ ملفات العمل دون إنترنت.
بعدها تقدر تفصل الإنترنت وتجرب التنقل أو تحديث الصفحة؛ الحساب المسجل سابقاً وبياناته المحلية يبقون متاحين.

السلوك الجديد
- انقطاع الإنترنت أو فشل تجديد جلسة الاتصال لا يمسح هوية الحساب المحفوظة ولا يرجع واجهة تسجيل الدخول تلقائياً.
- يستعيد نوع النشاط المحفوظ، مثل الحساب الشخصي أو المعالجات، بدل الرجوع إلى الواجهة العامة.
- يفتح بيانات الحساب المحلية قبل انتظار استعادة الاتصال بالخدمة.
- يحتفظ بالواجهة المفتوحة وبالنافذة الجاري العمل بها عند انقطاع الاتصال أو رجوعه.
- يحفظ التعديلات محلياً، ويعيد التحقق والمزامنة عند رجوع الاتصال. إذا ظهر تعارض، تبقى التعديلات محفوظة بانتظار مراجعته.
- لا يستبدل التعديلات الأحدث بحركة مزامنة بدأت قبل تسجيلها.
- ملف تشغيل الاتصال صار ضمن ملفات الموقع ومحفوظاً للعمل دون إنترنت.
- الخروج الاختياري من زر «خروج» يبقى يعمل، ولا يحذف السجلات المحلية.
- أول دخول لحساب جديد يحتاج الإنترنت. الإيقاف المؤكد من الأدمن يبقى نافذاً؛ لا يحذف هذا التحديث بيانات الحساب.

الفحص
نجحت اختبارات محاكاة إعادة الفتح دون إنترنت، وفشل أو غياب أو تأخر جلسة الاتصال مع وجود حساب محفوظ، وفشل خدمة الاشتراك، واختيار نوع النشاط الصحيح، وبقاء النافذة المفتوحة عند رجوع الاتصال، والخروج الاختياري، وحفظ التعديلات أثناء المزامنة، والرجوع إلى الصفحة المحفوظة عند فشل الشبكة أو خادم الموقع.
نجحت فحوص JavaScript ومراجعة وجود جميع ملفات التخزين المحلي. لم يُجرَ اختبار يدوي بجهازك أو بحسابك الحي.
