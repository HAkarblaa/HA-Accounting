التعديل الشامل وسجل التعديلات بالكشف — 20261119-voucher-edit-history-v21

الاستخدام:
من قائمة سندات القبض والدفع اضغط تعديل لتغيير رقم السند والتاريخ والمبلغ والطرف والحساب النقدي والحساب المقابل والملاحظات. احفظ التعديل.
لتصحيح إرجاع مرتبط، افتح تفاصيل الأصل أو تعديله ثم اضغط تعديل الإرجاع لتغيير المبلغ أو التاريخ أو الملاحظات.

سجل التعديل:
كل حفظ يغيّر قيمة فعلية يسجّل الحقل والقيمة قبل التعديل وبعده ووقت التغيير. الحفظ بدون تغيير لا يضيف سجلاً مكرراً.
يظهر جدول «سجل التعديلات — للبيان فقط» ضمن تفاصيل السند، وفي تفاصيله بالكشوف التفصيلية والطباعة وPDF. يتضمن تعديلات الإرجاعات المرتبطة بالأصل أيضاً. الوقت معروض بتوقيت بغداد، وتواريخ الحقول يوم/شهر/سنة.
سجل التعديل لا ينشئ قبضاً أو دفعاً إضافياً؛ يحتسب الرصيد من الحركة المصححة مرة واحدة. يظل الإرجاع حركة محاسبية داخلية محسوبة مع إظهار تفاصيله ضمن الأصل.
تُحفظ السجلات من وقت تركيب هذا التعديل فما بعده؛ لا يمكن استنتاج القيم القديمة لتعديلات لم يسجّلها البرنامج سابقاً. تبقى قيود مبالغ الإرجاع والتواريخ والتوزيعات والصلاحيات الموجودة كما هي.
التعديلات تسجّل ضمن تفاصيل السند نفسه بالكشف، وليست قيوداً مالية مستقلة. عند تحديد فترة للكشف لا تظهر سجلات تعديل مؤرخة بعد نهايتها.

التركيب:
فك الضغط وارفع الملفات إلى جذر HA-Accounting مع استبدال المطابق. احتفظ ببقية ملفات المشروع وبملف supabase-config.js. انتظر اكتمال النشر ثم اضغط تحديث البرنامج بعد حفظ شغلك. لا يحتاج SQL أو نشر دوال Supabase أو حذف التطبيق أو مسح بياناته.
الحزمة تشمل ملفات التعديلات السابقة: الإرجاع ضمن الأصل، صلاحية المنتج وألوانه، صيغة التاريخ، تخصيص المربعات، إصلاح الموبايل والباركود والتحديث التلقائي.

التحقق المحلي:
تغيير بيانات الأصل والإرجاع، حفظ قبل وبعد، عدم تكرار سجل عند عدم التغيير، نقل حساب الصندوق للمصرف مع بقاء الرصيد الصحيح، عرض السجل بالتفاصيل والطباعة والكشف وتصفية التاريخ، وهروب النصوص لمنع تفسيرها كـHTML. لم يجر اختبار على جهاز أو طابعة فعلية.
