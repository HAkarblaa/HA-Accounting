تحديث الشركاء وفرعيات الشريط المختصر وإظهار المصروفات — الإصدار 40

التثبيت:
فك الضغط وارفع الملفات البرمجية الأحد عشر إلى جذر مشروع HA-Accounting بنفس أسمائها، واستبدل القديم. انتظر اكتمال رفع الملفات ثم افتح البرنامج واضغط تحديث البرنامج. لا تمسح بيانات المتصفح أو التطبيق.
الحزمة تحتوي ملفات التعديل كاملة، وتحتاج بقية ملفات المشروع السابقة. لا تحتاج SQL أو نشر Edge Function جديدة. لا ترفع README أو SHA256SUMS إذا لا تريد ظهورهما بالمستودع؛ هما للشرح والتحقق فقط.

الشركاء داخل المعالجات:
- مربع باللوحة، وقائمة جانبية، واختصار سفلي بفرعيات.
- تسجيل اسم الشريك والهاتف والعنوان والملاحظات وتاريخ البداية، وتعديل معلوماته مع حفظ تاريخ التغيير.
- مساهمات متعددة بالصندوق أو المصرف. تسجيلها رأس مال؛ لا تضخم الإيرادات.
- نسب ربح وخسارة مستقلة، كل مجموع 100٪. كل تغيير يحفظ بتاريخ جديد دون تغيير النسب السابقة.
- سحب رأس مال وصرف أرباح بشكل منفصل، ضمن الرصيد المسجل المتاح لكل نوع.
- معاينة توزيع الربح أو الخسارة لفترة، ثم اعتماد الحصص. اعتماد الربح لا يصرفه نقداً؛ الصرف حركة أخرى.
- تتوفر أداة لجلب تقدير الفترة للمراجعة. مبلغ التوزيع النهائي يُدخل ويُعتمد مع بيان أساسه؛ راجع الرواتب والضرائب والتسويات التي لا يشملها التقدير. لا تعتبر الأداة إقفالاً محاسبياً تلقائياً.
- لا يمكن تكرار أو تداخل فترة معتمدة، وإذا تغيرت النسب أثناء الفترة يجب تقسيمها عند تاريخ التغيير. اعتمد الفترات بالترتيب الزمني.
- الخسائر المخصصة تنقص رأس مال الشريك؛ وقد يصبح رصيده سالباً، ويجب تغطية العجز قبل التسوية.
- تسوية الشريك تصرف رأس المال والأرباح المتبقية بحركتين من الحساب المختار. إيقافه يتطلب رصيداً صفراً، وحصة صفراً في أحدث نسب محفوظة. التاريخ والسجلات يبقيان محفوظين.
- كشف لكل شريك بفترة ورصيد افتتاحي وختامي، وطباعة وPDF. توجد طباعة وPDF للتقرير الإجمالي أيضاً.
- القيود المالية المعتمدة لا تحذف من دفتر اليومية العام. تعديل معلومات الشريك لا يعيد كتابة المساهمات أو التوزيعات المعتمدة.
- القسم لصاحب حساب المعالجات والأدمن، ولا يضاف إلى شاشة الموظف المحدودة. يبقى ضمن مساحة الحساب الحالية والتجربة المعزولة إذا دخلتها.

أول استخدام مقترح:
أضف الشركاء بتاريخ بدايتهم، ثم احفظ نسبهم من تاريخ بدء الشراكة، ثم سجل المساهمات. بعدها افتح توزيع فترة، راجع صافي الربح أو الخسارة وأدخل البيان، اضغط معاينة ثم اعتماد. لصرف الحصص استخدم صرف أرباح.

الشريط المختصر:
الأقسام ذات الفرعيات تفتح قائمة بأيقونات فوق الشريط، وتعيد استخدام الأوامر والصلاحيات الموجودة بالقائمة الجانبية. خيار فتح القسم يبقي الوصول إلى الصفحة الرئيسية للقسم. الرئيسية والرجوع يحتفظان بوظيفتهما. الأقسام الخارجية التي لا توفر فرعيات داخل البرنامج تحتفظ بسلوكها السابق.

المصروفات:
المصروفات كانت ضمن مجموعة الموظفين والمصاريف، والوصول إليها من صفحات المعالجات في الواجهة الكاملة كان محجوباً. أصبحت مجموعة مستقلة مع إضافة مصروف وسجل وطباعة كشف وPDF، واختصار بالشريط السفلي. المسار الجديد processor-expenses يقرأ نفس سجل المصروفات السابق، ولا ينقله أو يمسحه.

التعديلات السابقة:
تثبيت التبويبات وتصميم سند القبض والدفع موجودان بالحزمة. بقية وظائف المشروع تستخدم ملفاتها الحالية.

الفحص:
فُحصت أوامر الشركاء وحساباتهم بالتقريب الدقيق، مجموع النسب، منع التداخل والسحب الزائد، ثبات النسب السابقة، ربط رأس المال بكشف الصندوق والمصرف، منع الحفظ إلى حساب مختلف، واسترجاع العملية كاملة عند فشل الحفظ. فُحصت الفرعيات والصلاحيات والمصروفات القديمة والتزامن والتحديث، وفحوص تمرير الموبايل والفواتير والسندات السابقة. روجعت معاينة ثابتة للواجهة؛ لم يجر اختبار على هاتف أو طابعة فعلية.
