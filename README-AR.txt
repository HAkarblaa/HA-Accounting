الاستخدام:
داخل نافذة فاتورة البيع أو الشراء في قسم المعالجات يظهر حقل «انتهاء الصلاحية» لكل مادة، بجانب الكمية. اختر التاريخ إذا كان المنتج له صلاحية، أو اتركه فارغاً.
يمكن تعديل التاريخ أو مسحه من تعديل الفاتورة، ضمن قيود التعديل الموجودة أصلاً. يظل تعديل أصل الفاتورة المرتبط بمرتجع مقفلاً حسب قواعد البرنامج.
يظهر التاريخ تحت اسم المادة عند عرض الفاتورة وطباعتها وحفظها PDF، في تخطيط A4 والوصل الحراري الصغير. يشمل أيضاً البيع المباشر داخل نافذة المعالجات الاعتيادية.

التاريخ محفوظ مع بند الفاتورة نفسه؛ إذا اشتريت نفس المنتج بصلاحيتين مختلفتين أضفه بسطرين وحدد تاريخ كل سطر. لا يخمن التعديل تاريخاً من آخر شراء، ولا يغيّر تواريخ فواتير قديمة تلقائياً. لا يضيف منع بيع أو تحذيرات انتهاء جديدة، ولا يغيّر نظام سحب دفعات المخزون أو كلفتها.

هذه إضافة إلى نوافذ فواتير المعالجات الاعتيادية. واجهة الموظفين المستقلة وصلاحياتها لم تتغير بهذا التعديل.
الحقل اختياري ولا يغيّر حسابات الأسعار أو الخصومات أو الضرائب أو التوصيل أو الدفعات. الفواتير القديمة بدون هذا الحقل تبقى كما هي حتى تعدّلها.

الحزمة تشمل ملفات التعديلات السابقة: حدود الموبايل، تسمية اسم المنتج، تخصيص مربعات المعالجات، ثبات الباركود، والتحديث التلقائي. لا تحتاج SQL أو نشر دوال Supabase أو حذف التطبيق أو البيانات.

التحقق المحلي: إنشاء بيع وشراء مع تاريخ، حفظ وإعادة فتح وتعديل ومسح، صلاحية تاريخ التقويم، تصحيح خطأ دون إغلاق النموذج، ظهور التاريخ بتخطيطي الطباعة، وبقاء المبالغ والدفعات دون تغيير. نجحت فحوص النماذج والمرتجعات والكشوف والطباعة والتحديث. لم يجر اختبار على هاتف أو طابعة فعلية.
