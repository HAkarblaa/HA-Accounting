فواتير البيع والشراء بترتيب يملأ مساحة الشاشة — الإصدار 41

فك الضغط وارفع الملفات البرمجية الـ13 إلى جذر مشروع HA-Accounting مع استبدال النسخ القديمة، وانتظر اكتمال الرفع ثم اضغط تحديث البرنامج. لا تمسح بيانات المتصفح أو التطبيق. هذه حزمة تعديلات تحتاج بقية ملفات المشروع السابقة، وليست المشروع الكامل.

نطاق التعديل:
يخص إنشاء وتعديل فواتير البيع والشراء داخل المعالجات، ويشمل البيع المباشر الذي يستخدم نفس النموذج. نماذج الأقسام الأخرى وقوالب الطباعة الحالية تبقى كما كانت.

الواجهة:
- مساحة فاتورة واسعة، وبيانات أساسية مختصرة بالأعلى، والمواد بالوسط، والخصم والضريبة والتوصيل والدفع والمجاميع بالأسفل، وأزرار الحفظ والإلغاء والطباعة واضحة.
- على الكمبيوتر بمساحة عرض لا تقل عن 1000×580 بكسل، تبقى الفاتورة داخل مساحة العرض ويكون سحب صفوف المنتجات داخل جدولها، مع ثبات عناوين أعمدته.
- الحقول الأصلية لم تُنسخ أو تُحذف. الملاحظات أصبحت ضمن البيانات العلوية.
- زر تفاصيل الدفع والصرف يفتح لوحة فيها سعر الصرف وحالة التوصيل وتوزيع النقد والتحويل والاستحقاقات والتفصيل الحسابي. وتبقى إضافة زبون أو منتج جديد متاحة من نفس الأزرار.
- عند اختيار الدولار أو الآجل أو الأقساط أو تقسيم الدفعة بين الصندوق والمصرف تفتح التفاصيل المناسبة تلقائياً. إذا احتاج حقل داخلها إلى تصحيح تظهر اللوحة عند التحقق.
- على الموبايل أو عند ضيق ارتفاع الشاشة تُرتب الأجزاء عمودياً للسماح بإدخال مقروء؛ قد تحتاج للتمرير. لا تُصغّر الحقول إلى حجم غير قابل للاستخدام.

الحفظ والطباعة:
حفظ وطباعة يحفظ أولاً عبر الوظيفة الأصلية، ثم يفتح طباعة نفس الفاتورة بعد نجاح الحفظ. الحفظ العادي لا يطبع. لا يُنشأ وصل مكرر. تبقى الحسابات والمخزون والدفعات والنسب والتواريخ بوظائفها الأصلية. تغيير التاريخ وحده يحافظ على بيانات الدفع السابقة.

تتضمن الحزمة أيضاً ملفات الشركاء وفرعيات الشريط المختصر وتصحيح المصروفات وتصميم السندات من الإصدار السابق لضمان توافقها مع index.html، وتثبيت التبويبات ما زال موجوداً. لا توجد أوامر حذف بيانات أو تغييرات SQL أو Edge Functions.

التحقق:
فُحصت إنشاء وتعديل فواتير البيع والشراء بالنقد والآجل والأقساط، تغيير التاريخ، العملات والتوصيل والمرتجعات، حفظ وطباعة الفاتورة الصحيحة مرة واحدة، إضافة وحذف الصفوف، الاحتفاظ بعناصر الإدخال ومعالجاتها، عدم تكرار الحقول، لوحات التفاصيل والمنتج الجديد، وفشل الحفظ وتصحيح المدخلات. فُحص توافق التحديث والتخزين دون اتصال، والشركاء والفرعيات والمصروفات والموبايل منطقياً. تمت مراجعة معاينة ثابتة للتنسيق؛ لم يجر اختبار في متصفح فعلي أو على هاتف أو طابعة فعلية.
