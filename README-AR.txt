تخصيص مربعات لوحة المعالجات — إصدار 20261118-dashboard-layout-v14

التركيب:
فك الضغط وارفع ملفات البرنامج إلى جذر مستودع HA-Accounting مع استبدال الملفات المطابقة. انتظر اكتمال نشر GitHub Pages. احتفظ ببقية ملفات المشروع وملف supabase-config.js الحالي.

الاستخدام:
افتح لوحة المعالجات واضغط «تخصيص المربعات» قرب عنوان اللوحة.
توجد قائمتان: الأقسام والاختصارات، والأرقام والإحصائيات.
أزل علامة الصح لإخفاء المربع، وأعدها لإظهاره.
غيّر الترتيب بالسحب على الأجهزة الداعمة، أو بأزرار تقديم وتأخير المناسبة للموبايل والكيبورد.
الترتيب يبدأ من اليمين في صف الحاسبة ومن الأعلى عند عرض عمود واحد.
اضغط حفظ التخصيص لتطبيق الاختيارات. إلغاء يغلق دون حفظ.
زر الترتيب الافتراضي وإظهار الكل يعيد جميع المربعات بترتيبها الأصلي داخل شاشة التخصيص؛ اضغط حفظ لتطبيقه.
يمكن إخفاء جميع المربعات؛ يبقى زر التخصيص متاحاً لإرجاعها.

الحفظ:
تُحفظ الاختيارات داخل بيانات حساب المحاسبة وبآلية الحفظ والمزامنة الموجودة. تعمل محلياً دون إنترنت وتُزامن عند عودة الاتصال. لا يخفي هذا التعديل الأقسام من القائمة الجانبية، ولا يمنح صلاحيات جديدة أو يغير صلاحيات الموظفين. المقصود ترتيب واختيار المربعات الموجودة، وليس إنشاء قسم محاسبي جديد.

لا تُحذف بيانات القسم عند إخفاء مربعه ولا تتغير الأرصدة أو حسابات الربح. لا يحتاج SQL أو نشر دوال Supabase أو إعادة تثبيت التطبيق.
الحزمة تشمل أيضاً ملفات التحديث التلقائي وثبات كاميرا الباركود السابقة؛ يمكنك رفع هذه الحزمة وحدها إذا لم ترفع الحزم السابقة.

التحقق:
فحوص محلية للإخفاء والإرجاع والترتيب بالأزرار والسحب، الحفظ وإعادة التحميل، الإلغاء، استعادة الافتراضي، فشل الحفظ، فصل إعدادات الحسابات، مزامنة التفضيلات، وبقاء بيانات المال والفواتير. نجحت فحوص المرتجعات والكشوف وتفعيل التحديث. لم يُختبر على موبايل فعلي.
