تحديث مواعيد العمل — الحسابات الشخصية

المزايا:
- قسم مواعيد العمل في الواجهة الشخصية والقائمة الجانبية وشريط الاختصارات.
- إضافة عنوان الموعد، اسم الشخص، الهاتف، التاريخ، وقت البداية والنهاية، المكان والملاحظات.
- تعديل الموعد وحذفه وتحديده مكتمل أو ملغى وإعادة فتحه.
- عرض مواعيد اليوم والقادمة والمكتملة والملغاة وجميع المواعيد، مع البحث والطباعة.
- حفظ المواعيد ضمن بيانات الحساب والعمل دون إنترنت، والمزامنة عبر آلية البرنامج عند الاتصال.
- المواعيد لا تضيف أي حركة للصندوق أو المصرف ولا تغيّر الديون.
- هذا القسم لا يتضمن إشعارات تذكير تلقائية.

التركيب:
1. احتفظ بنسخة احتياطية من الموقع وبيانات الحساب.
2. استبدل الملفات الثلاثة المرفقة في المجلد الرئيسي للموقع:
index.html
auth-client.js
service-worker.js
3. اترك بقية ملفات الموقع كما هي، ومنها ملفات الطباعة.
4. بعد اكتمال نشر GitHub Pages أغلق البرنامج وافتحه، أو حدّث الصفحة لتحميل النسخة الجديدة.
5. ادخل بحساب نشاطه حساب شخصي، ثم افتح مواعيد العمل.

الفحص:
فُحصت النماذج والإضافة والتعديل والحذف والبحث والفلاتر وحفظ بيانات الموعد ودمج المزامنة برمجياً، مع إعادة فحص وظائف الديون والتحديث اليدوي والطباعة الشخصية. لم يُختبر هذا التحديث على هاتف فعلي.
