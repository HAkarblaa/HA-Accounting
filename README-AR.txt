إضافة مربع المجموع الكلي للحساب الشخصي.
المجموع = رصيد الصندوق + رصيد المصرف. يتحدث تلقائياً مع الحركات المحفوظة.
بالضغط عليه تظهر تفاصيل الرصيدين والمجموع، مع الوصول إلى كشف الصندوق وكشف المصرف.
إظهار المجموع لا ينشئ حركة نقدية جديدة، والتحويل بين الصندوق والمصرف لا يغير مجموعهما.
يبقى ترتيب الموبايل ثلاثة مربعات لكل صف.
ارفع index.html و service-worker.js إلى جذر الموقع مع الاستبدال، وبعد النشر حدّث الصفحة.
