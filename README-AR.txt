تحديث قسم المعالجات: الجرد وكشوف الحساب والتقارير

محتويات الملف المضغوط
- index.html: ملف الواجهة المحدّث.
- README-AR.txt: هذه التعليمات.

التغييرات ضمن قسم المعالجات فقط
- إضافة صفحة جرد للمخزون تسجّل الكمية الفعلية والفرق، وتحدّث رصيد منتجات المعالجات فقط بعد تأكيد الحفظ.
- حفظ سجل عمليات الجرد وعرضه في تقارير الفترة.
- فصل صفحات الزبائن عن صفحات المجهزين.
- إضافة كشف حساب لكل زبون أو مجهز، يعرض بياناته وفواتيره والمبالغ الإجمالية والمدفوعة والمتبقية والدفعات المسجلة.
- تقارير من تاريخ إلى تاريخ للمبيعات والمشتريات وحركات الزبائن والمجهزين والديون والجرد، مع عرض رصيد المخزون الحالي.
- الكاشير ليس ضمن قائمة قسم المعالجات.

طريقة التثبيت
1. فك الضغط.
2. استبدل ملف index.html في جذر موقعك بالملف الموجود هنا.
3. لا تمسح بيانات المتصفح ولا تستعد نسخة احتياطية للبيانات عند تركيب هذا التحديث. لا يتضمن هذا التحديث أوامر SQL أو حذفاً للبيانات؛ سجل الجرد الجديد يُحفظ ضمن بيانات المعالجات الحالية.
