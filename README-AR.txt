HA محاسبة — حزمة مستقلة للنشر على GitHub Pages

طريقة النشر:
1) أنشئ مستودع GitHub جديد باسم HA-Accounting، حتى يبقى منفصلاً عن HA-Marketing.
2) فك ضغط هذه الحزمة وارفع كل الملفات والمجلدات الموجودة داخلها إلى جذر المستودع (مكان ظهور Add file).
3) افتح Settings ثم Pages.
4) ضمن Build and deployment اختر Deploy from a branch، ثم الفرع main والمجلد /(root)، واضغط Save.
5) بعد اكتمال النشر افتح الرابط الذي يظهر في صفحة Pages. افتح الموقع مرة واحدة مع الإنترنت ثم اختر تثبيته/إضافته إلى الشاشة الرئيسية من المتصفح.

مزايا النسخة:
- تعمل كصفحة ويب قابلة للتثبيت على الهاتف والكمبيوتر.
- تحفظ نسخة التطبيق وتفتح الواجهة دون اتصال بعد أول زيارة ناجحة.
- مناسبة كخطوة أولى قبل تغليفها كتطبيق أندرويد.

تنبيه بيانات:
يلزم تسجيل الدخول بحساب مفعّل. يحتفظ البرنامج بنسخة محلية على الجهاز ويزامن مساحة الحساب مع Supabase عند الاتصال بالإنترنت. نزّل نسخة JSON احتياطية بانتظام. لا تضع بيانات فعلية حساسة في مستودع عام؛ البيانات التشغيلية لا تُرفع إلى GitHub.

تشغيل محلي سريع:
افتح index.html بمتصفح حديث. خصائص التثبيت والعمل دون اتصال تتطلب استضافة HTTPS مثل GitHub Pages أو خادماً محلياً؛ فتح الملف مباشرة لا يفعّل service worker.


تحديث هذه النسخة: ألوان أوضح، صور منتجات داخل بطاقات الكاشير والمخزون، أصناف عرض للأجهزة والأطعمة والعصائر، وطباعة الفواتير على A4 أو وصل 80/58 ملم مع دعم جسر الطباعة في التطبيق. تغييرات الموقع التي تعتمد على حساب HA Marketing ومزامنة متجره لا تعمل تلقائياً هنا لأن هذا البرنامج مربوط بمشروع Supabase مستقل؛ يلزم توحيد قاعدة الحسابات قبل نقل المزامنة.


تفعيل تسجيل الدخول
راجع ملف README-LOGIN-AR.txt وشغّل setup-login.sql في مشروع Supabase نفسه، ثم أنشئ الأدمن الأول وانشر Edge Function قبل فتح الموقع للمستخدمين.

- المصاريف التشغيلية المتكررة: أضف الإيجار أو المولدة أو الكهرباء وغيرها، بمبلغ يومي أو شهري موزع يومياً، مع ترحيل محاسبي يومي وإمكانية تسديد المبالغ المستحقة.
