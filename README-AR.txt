مربعات المرتجعات والكشوف التفصيلية — 20261119-return-dashboard-statements-v25

أضيفت أربعة مربعات بلوحة المعالجات:
- مرتجعات المبيعات.
- مرتجعات المشتريات.
- مرتجعات القبض.
- مرتجعات الدفع.
كل مربع يعرض عدد العمليات وقيمتها بالدينار، ويفتح سجل نوعه. يمكن إخفاء المربعات أو إرجاعها وترتيبها من تخصيص المربعات. الترتيب والاختيارات القديمة لا تُلغى؛ المربعات الجديدة تُضاف إليها.

الكشف:
داخل كل سجل زر «كشف تفصيلي». حدد من/إلى تاريخ والطرف، ثم عرض الفترة أو طباعة الكشف أو حفظ PDF.
يشمل تاريخ الإرجاع والطرف والنوع وعام أو تفصيلي، المواد والكميات والوحدات وسعر الأصل، المبلغ المرتجع والتوصيل والملاحظات، والأصل ومجموع مرتجعاته والصافي حتى نهاية الفترة. تعديلات السندات تظهر ضمن التفاصيل للبيان.
مجموعة الإرجاع العام تُعد عملية واحدة، لكن الكشف يفصّل الأجزاء حسب ارتباطها الداخلي بالأصول؛ كل جزء يُجمع مرة واحدة. قيم الأصل والصافي بجانب التفاصيل للبيان وليست مبالغ تُجمع ثانية.
المبالغ الإجمالية بالدينار العراقي، وأسعار المواد بالأصل تظهر بعملة وسعر صرف الأصل.

حركة الأموال:
قسم مستقل داخل الكشف يعرض القبض أو الدفع الفعلي المرتبط بالمرتجعات بتاريخ حصوله. قد يخص مرتجعاً من فترة سابقة؛ لذلك لا تُجمع حركة الأموال مع قيمة المرتجعات، ولا يختلط كشف المرتجعات مع رصيد دين الشخص.
هذا كشف للمرتجعات وحركات أموالها، وليس كشف رصيد الصندوق أو رصيد دين الزبون. تبقى كشوف الحساب السابقة متاحة من أقسامها.

التركيب:
فك الضغط وارفع الملفات إلى جذر HA-Accounting مع استبدال المطابق. احتفظ ببقية الملفات وsupabase-config.js. انتظر اكتمال النشر ثم اضغط تحديث البرنامج بعد حفظ العمل.
الحزمة تشمل التعديلات السابقة: عام وتفصيلي، تعديل السند والإرجاع وسجله، التالف والمنتهي، الصلاحية وألوانها، تخصيص اللوحة، إصلاح الموبايل والتحديث التلقائي. لا يحتاج SQL أو نشر دوال أو حذف التطبيق أو بياناته.

التحقق المحلي:
ظهور المربعات الأربعة، مفاتيح تخصيص مستقلة مع حفظ الترتيب السابق، تصفية السجلات حسب النوع، كشوف لكل نوع والطرف والفترة، الإجماليات، فصل رد الأموال المتأخر عن تاريخ المرتجع، عدم تغيير البيانات، واستدعاء الطباعة وPDF. نجحت فحوص إنشاء المرتجعات والسندات والتحديث أيضاً. لم يجر اختبار على جهاز أو طابعة فعلية.
