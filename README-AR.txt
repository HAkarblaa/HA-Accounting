تصحيح أزرار المرتجعات والإضافة — 17/11/2026

السبب:
معالج أزرار المرتجعات كان مربوطاً بالأزرار الموجودة داخل النوافذ فقط، ولم يكن مربوطاً بأزرار صفحة المرتجعات والفواتير والسندات. لذلك الضغط على إضافة مرتجع أو ترجيع الفاتورة أو عكس السند من الصفحة لم يفتح شيئاً.

التصحيح:
- ربط أزرار الصفحة بمعالج المرتجعات نفسه.
- زر مرتجع / عكس سند يفتح نافذة اختيار نوع الأصل ورقمه.
- زر ترجيع من فاتورة البيع أو الشراء يفتح نموذج الترجيع مباشرة.
- زر عكس السند يفتح نموذج العكس من سجل السندات.
- باقي إجراءات المرتجع، مثل العرض والطباعة والحفظ وتسوية المبلغ، مرتبطة بنفس معالج الصفحة.
- عند عدم وجود فواتير أو سندات من النوع المختار تظهر رسالة واضحة، بدلاً من بقاء الاختيار فارغاً دون شرح.

الاستخدام:
1. افتح المرتجعات والإلغاءات ثم اضغط + مرتجع / عكس سند.
2. اختر النوع: فاتورة بيع أو شراء أو سند قبض أو دفع.
3. اختر رقم الفاتورة أو السند؛ بعدها يتفعّل زر متابعة.
4. اضغط متابعة وحدد كميات الترجيع أو مبلغ عكس السند، ثم احفظ.
إذا كانت القائمة فارغة غيّر النوع، أو سجّل فاتورة/سند أولاً.

التركيب:
هذه الحزمة تحتوي الملفات الحالية مع تصحيح الربط وملفات الطباعة السابقة حتى لا تنقص أي تبعية.
ارفع ملفات البرنامج الموجودة داخل الضغط إلى المجلد الرئيسي للموقع، مع استبدال الموجود، وأبقِ بقية ملفات الموقع وبياناتك كما هي.
بعد انتهاء نشر GitHub Pages حدّث البرنامج. على الكمبيوتر يمكنك إعادة تحميل الصفحة بـ Ctrl+Shift+R بعد النشر. وعلى الموبايل أغلق البرنامج وافتحه متصلاً بالإنترنت أو استخدم تحديث البرنامج.
لا تمسح بيانات الموقع أو سجل الحساب لإجراء هذا التصحيح.

الفحص:
تم فحص مسار الضغط الفعلي برمجياً من الصفحة: فتح نافذة الإضافة، اختيار الأصل، فتح نموذج الترجيع وحفظ مرتجع كامل، زر الترجيع في سجل الفواتير، رسالة السجلات الفارغة، وفتح عكس سند الدفع وحفظ سند القبض المقابل.
نجحت كذلك اختبارات حسابات المرتجعات والمخزون والدفعات والكشوف والمزامنة ذات الصلة.
هذا ليس اختباراً على جهاز المستخدم أو على النسخة المنشورة؛ يلزم رفع الملفات كي يصل التصحيح للموقع.
