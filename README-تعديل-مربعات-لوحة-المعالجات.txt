تعديل مربعات لوحة المعالجات

التعديل:
- عرض 5 مربعات في السطر الأول و3 مربعات في السطر الثاني على شاشة الكمبيوتر.
- عرض 3 أعمدة على الشاشات المتوسطة وعمودين على الهاتف.
- إضافة مربع «عدد الفواتير» لإكمال ثمانية مربعات.
- لا يتغير أي قسم أو حساب آخر.

طريقة التركيب:
1. فك ضغط الملف.
2. ارفع index.html و service-worker.js إلى جذر مستودع HA-Accounting على GitHub، واستبدل الملفين الموجودين.
3. انتظر اكتمال GitHub Pages، ثم حدّث الموقع تحديثاً إجبارياً باستخدام Ctrl+F5. على الهاتف أغلق الصفحة وافتحها مجدداً.

يشمل الملفين المعدلين وهذا الشرح فقط.
