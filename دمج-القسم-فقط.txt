القسم اليمني — إضافة مستقلة
============================

هذا الملف المضغوط يحتوي ملفات القسم اليمني وحده، وليس نسخة من الموقع. ملفات الواجهة تستخدم CSS وأسماء بيانات خاصة بالقسم. سجل الفواتير والحركات والإعدادات محفوظ تحت بيانات القسم فقط.

المحتويات:
- yemen-section.js: واجهة القسم، الحركات، الفواتير، العملتان، التقارير والطباعة.
- yemen-section.css: تنسيق القسم المتجاوب للموبايل والحاسوب.
- demo.html: معاينة محلية؛ تفتحها بالمتصفح لتجربة القسم. تخزين المعاينة منفصل بمفتاح خاص.
- yemen-module-type.sql: يضيف نوع النشاط للقائمة المسموحة في قاعدة البيانات.

العملات:
- الأساسية: الدينار العراقي IQD.
- الثانية: الدولار الأمريكي USD.
- أدخل سعر الصرف من إعدادات القسم بصيغة: 1 USD = عدد من IQD.
- يظهر التحويل مباشرة في الفاتورة والحركة. كل فاتورة تحفظ سعر الصرف المستخدم؛ تحديث السعر لا يغيّر الفواتير السابقة.

الفواتير:
- إنشاء فاتورة مبيعات أو مشتريات مع عدة مواد وكميات وأسعار.
- حفظ الفاتورة في سجل القسم بشكل مستقل.
- «طباعة / حفظ PDF» يفتح نافذة الطباعة؛ اختر طابعة أو «Save as PDF / حفظ كملف PDF».

الدمج داخل الموقع يحتاج إضافة رابط للقسم وتحميل ملفي CSS وJavaScript فقط. نقطة الدمج تكون في حاوية القسم المخصصة، وتُمرر بيانات yemen مستقلة مثل:

<link rel="stylesheet" href="./yemen-section.css">
<script src="./yemen-section.js"></script>
<div id="yemenSection"></div>
<script>
  const yemenSection = HAYemenSection.mount(document.getElementById('yemenSection'), {
    data: accountState.yemen,
    onSave: next => { accountState.yemen = next; saveAccountState(); }
  });
</script>

بدّل accountState وsaveAccountState بأسماء مخزن الحساب ودالة الحفظ الموجودة عندك. لا تمرر state العام كاملاً؛ مرر فقط accountState.yemen حتى تبقى بيانات الأقسام الأخرى خارج هذا الجزء.

حتى يظهر الاختصاص للأدمن عند إنشاء أو تعديل الحساب، يلزم أيضاً إضافة خيار «القسم اليمني» لقائمة الأنشطة، والسماح بالقيمة yemen في دالة إدارة الحسابات. ملف SQL هنا يحدّث قيد قاعدة البيانات. هذه خطوات دمج قصيرة وليست استبدالاً لملفات الموقع.
