تحديث قوائم الزبائن والمجهزين والبحث عن المنتجات

الملفات:
- index.html
- service-worker.js

التثبيت:
1. احتفظ بنسخة احتياطية من الملفين الحاليين.
2. ارفع الملفين إلى جذر مستودع الموقع واستبدل النسخة الحالية.
3. انتظر نشر GitHub Pages ثم حدّث الموقع. إذا ظهرت نسخة قديمة على الهاتف، أغلق التطبيق وافتحه من جديد.

التغييرات:
- فصل سجل الزبائن عن سجل المجهزين في قوائم مستقلة، مع حقول الهاتف والبريد والعنوان والملاحظات والرصيد الافتتاحي.
- صفحة المعالجات تحتوي كذلك على قائمتين منفصلتين للزبائن والمجهزين.
- فواتير البيع تعرض الزبائن فقط، وفواتير الشراء تعرض المجهزين فقط. حقول سندات القبض والصرف تعرض القائمتين ضمن مجموعتين منفصلتين.
- فواتير الهندسة تستخدم قائمة الزبائن للبيع وقائمة المجهزين للشراء. أسماء زبائن الصيانة الجديدة تُسجل ضمن قائمة الزبائن.
- البحث عن المنتجات في فواتير البيع والشراء والكاشير يظهر اقتراحات عند كتابة الاسم أو جزء منه ويصفّي المنتجات فوراً.
- يتضمن التحديث أيضاً التعديلات السابقة: الرجوع للصفحة السابقة، البقاء بنفس الصفحة بعد التحديث، تعديل كميات المخزون، وفصل المدين والدائن بأقساط الواجهة المبسطة.

حفظ البيانات:
التحديث لا يمسح بيانات الزبائن أو المجهزين أو الفواتير. السجلات الحالية تبقى محفوظة، والحقول الجديدة تظهر عند تعديل بيانات الجهة وحفظها.
