تحديث قسم الهندسة والمقاولات + إصلاح الأقسام والتواريخ

المحتويات:
- index.html وauth-client.js وservice-worker.js: ملفات الموقع، ارفعها إلى جذر مستودع HA-Accounting واستبدل النسخ القديمة.
- engineering-module-type.sql: تحديث قاعدة البيانات مرة واحدة لإتاحة نوع الحساب «هندسة ومقاولات» مع الحفاظ على الأنواع الحالية.
- manage-subscribers-index.ts: مصدر Edge Function المحدث حتى يقبل نوع الحساب الجديد.

التركيب:
1) خذ نسخة احتياطية من ملفات الموقع الحالية.
2) في Supabase SQL Editor شغّل ملف engineering-module-type.sql مرة واحدة.
3) حدّث Edge Function باسم manage-subscribers باستخدام محتوى manage-subscribers-index.ts، مع إبقاء أسرار Supabase في إعدادات الدالة فقط.
4) ارفع index.html وauth-client.js وservice-worker.js إلى جذر مستودع GitHub واستبدل الملفات القديمة.
5) بعد اكتمال النشر، افتح التطبيق من جديد أو نفّذ Ctrl+F5.
6) من إدارة الحسابات، اختَر «هندسة ومقاولات» للحساب الذي تريد تخصيصه لهذا القسم.

تفاصيل الهندسة:
- سجل مستقل للبيوت والمشاريع، صاحب المشروع، الهاتف، الموقع، قيمة الاتفاق والرصيد.
- قبض دفعات من صاحب المشروع، وتسجيل المصاريف وسلف/دفعات العمال والوسطاء مع أسمائهم وتفاصيلها.
- مخزون مواد مستقل للهندسة؛ فواتير شراء وبيع متعددة المواد، نقداً أو جزئياً أو على الحساب، مع تسجيل الدفعات اللاحقة وطباعة الفواتير.
- فواتير الشراء تزيد مخزون مواد الهندسة، وفواتير البيع تخصم منه. لا تغيّر مخزون السوق أو فواتير أقسام المحاسبة العامة.
- دفتر حركة الهندسة ورصيد كل مشروع محفوظان داخل القسم.

تتضمن الحزمة كذلك إصلاح أزرار إدارة أقسام المنتجات، وعرض التواريخ يوم/شهر/سنة. قسم الهندسة لا يظهر للحسابات المتخصصة الأخرى؛ يظهر للأدمن أو للحساب المحدد باختصاص الهندسة.
