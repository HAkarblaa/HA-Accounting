تحديث الرجوع بين الصفحات والاحتفاظ بالقسم عند تحديث الموقع

الملفات:
- index.html
- service-worker.js

التثبيت:
1. خذ نسخة احتياطية من الملفين الحاليين.
2. ارفع الملفين إلى جذر مستودع الموقع واستبدل النسخة الحالية.
3. انتظر اكتمال نشر GitHub Pages ثم حدّث الموقع. إذا بقيت نسخة قديمة على الهاتف، أغلق التطبيق وافتحه من جديد.

التغيير:
- كل انتقال بين أقسام البرنامج يحفظ الصفحة في سجل المتصفح والرابط.
- زر رجوع المتصفح أو الهاتف يرجع للقسم السابق داخل البرنامج.
- تحديث الصفحة يعيد فتح القسم الحالي من رابط ?page= بدل الانتقال إلى لوحة التحكم.
- لم تتغير بيانات الحساب أو الفواتير نتيجة هذا التعديل.

تتضمن الحزمة أيضاً آخر تعديلات البرنامج: تعديل كميات المخزون العام والهندسة والمعالجات، وفصل المدين والدائن بأقساط الواجهة المبسطة.
