تحديث قسم الورشة الصناعية

حُذف الكاشير / نقطة البيع من قسم الورشة الصناعية فقط:
- لا يظهر خيار الكاشير في القائمة الجانبية.
- لا يظهر مربع «فتح الكاشير» ضمن الإجراءات السريعة.

تبقى فواتير المبيعات والمشتريات، البيع المباشر، المخزون، الأقساط والاستحقاقات، الصندوق والبنوك، الزبائن والمجهزون، الموظفون والرواتب، التقارير وإعدادات الشركة متاحة.

هذا التعديل خاص بنوع حساب الورشة الصناعية. لا يغيّر الكاشير أو وظائف مركز الصيانة والاستبدال أو بقية الأقسام.

التثبيت:
استبدل الملفات الثلاثة المرفقة: index.html و auth-client.js و service-worker.js، ثم حدّث الموقع تحديثاً كاملاً.
