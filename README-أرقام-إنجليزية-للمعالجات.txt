تحديث الأرقام الإنجليزية لقسم المعالجات

يحوّل هذا التعديل الأرقام الظاهرة داخل قسم المعالجات إلى الأرقام الإنجليزية 0-9، ويشمل لوحة المعالجات، الفواتير، بيانات المخزون والجهات، التقارير، النوافذ، والطباعة/حفظ PDF.

التغيير محدود بقسم المعالجات ولا يغيّر تنسيق الأرقام في بقية الأقسام. يحتوي الملف المضغوط على index.html وservice-worker.js وملف الشرح هذا. بعد رفع الملفين إلى الموقع، حدّث الصفحة أو أعد فتحها ليتم تحميل النسخة الجديدة.
