توسعة قسم ورشة الصيانة

تمت إضافة صفحات البيع والتسوق العامة لقسم ورشة الصيانة مثل قسم الأسواق:
- الكاشير / نقطة البيع
- فواتير المبيعات والمشتريات
- الأقساط والاستحقاقات
- الصندوق والبنوك
- المخزون
- الزبائن والمجهزون
- الموظفون والرواتب
- التقارير

تم الإبقاء على تفاصيل الورشة الحالية كما هي، ومنها استلام الأعطال والوصولات، متابعة القطع والتسليمات، المصاريف والتقرير الخاص بالورشة. تضاف صفحات التسوق إلى جانبها ولا تستبدلها.

لا تظهر أدوات قارئ الباركود أو مسح الكاميرا في كاشير الورشة أو حقول البحث داخل فواتيرها؛ يبقى البحث باسم الصنف وإضافته من بطاقات المنتجات متاحاً.

التثبيت:
استبدل index.html و service-worker.js بالملفين في الحزمة. بعد الاستبدال حدّث الموقع تحديثاً كاملاً إذا بقيت النسخة القديمة في المتصفح.

تم فحص صياغة JavaScript المضمنة وملف service-worker.js باستخدام Node.js.
