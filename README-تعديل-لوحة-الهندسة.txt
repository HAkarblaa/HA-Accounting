تعديل لوحة قسم الهندسة والمقاولات وفصل الطباعة عن PDF

الملفات: index.html و service-worker.js و ha-business-print.js

التركيب: استبدل الملفات الثلاثة بنسخها في ملفات الموقع ثم ارفع التعديل إلى GitHub Pages. تم تغيير رقم ذاكرة التخزين المؤقت كي يحمل المتصفح الملفات الجديدة.

المزايا: مربعات صافي الربح والإيرادات والمصروفات والصندوق والمصرف تفتح كشف حركات خاصاً بالهندسة؛ يمكن تحديد فترة، تصدير CSV، وطباعة الكشف أو حفظه PDF. يمكن تعديل رقم الفاتورة والتاريخ والجهة والمشروع والملاحظات دون تغيير المواد أو الكميات أو المبالغ. الفواتير الهندسية تطبع من نافذة الطباعة مع خيار PDF. التغييرات محصورة بتوجيه لوحة الهندسة وصفحاتها.

تنبيه محاسبي: صافي الربح المعروض تقديري ويحسب الإيرادات المسجلة ناقص مشتريات مواد الهندسة ومصاريف المشاريع. رصيد الصندوق والمصرف يحسب المقبوض والمدفوع بحسب جهة الدفع المسجلة.
