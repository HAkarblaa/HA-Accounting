تعديل قسم الهندسة والمعالجات

الملفات التي تستبدل بالموقع: index.html و service-worker.js و ha-business-print.js.

تظهر صفحة الهندسة قسمين: مشاريع الهندسة، والمعالجات. بيانات المعالجات محفوظة داخل ملف الحساب نفسه ومزامنتها تستفيد من حفظ النظام، لكن شاشاتها ومخزونها وفواتيرها منفصلة عن دفاتر مشاريع البيوت.

المعالجات: لوحة مؤشرات، مبيعات متعددة الأصناف، مشتريات تحدث مخزون المعالجات، زبائن ومجهزون، ديون واستحقاقات مع تسجيل دفعة، تقرير مالي بفترة محددة، طباعة/PDF. البيع يخصم المخزون، والشراء يضيفه. ربح المبيعات تقديري ويحسب المبيعات ناقص كلفة البضاعة المباعة المسجلة وقت البيع.

الهندسة: مشاريع وبيوت، قيمة الاتفاق، قبض ومصاريف ومشتريات مواد مرتبطة بالمشروع، وأجور عمال ونقل. مشتريات ومصاريف المشروع تبقى حركات تكلفة خاصة بالمشروع ولا تدخل مبيعات أو أرباح المعالجات.

لوحة الهندسة السابقة وتفاصيلها تبقى منفصلة. تم فحص صياغة JavaScript للملفات بعد التعديل.
