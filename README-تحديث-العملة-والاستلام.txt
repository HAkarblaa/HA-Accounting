تحديث فواتير قسم المعالجات

المحتويات:
- HA-Accounting-main/index.html

التحديث:
- اختيار العملة بالدينار العراقي أو الدولار في فواتير المبيعات والمشتريات.
- عند اختيار الدولار يُدخل سعر الصرف بالدينار لكل دولار، وتُعرض مبالغ الفاتورة بالدولار مع حفظ القيم المحاسبية بالدينار.
- خيارات استلام الدفعة: الصندوق (تم الاستلام نقداً)، أو المصرف (تم الاستلام عبر تحويل مصرفي)، أو اختيار الاثنين وتقسيم المبلغ بينهما.
- تظهر طريقة الاستلام والمبلغ في الفاتورة المطبوعة.

طريقة التطبيق:
استبدل ملف index.html الحالي بملف الحزمة داخل مجلد HA-Accounting-main، ثم ارفع التحديث بالطريقة المعتادة للموقع.

هذا التحديث يضيف الخيارات داخل قسم المعالجات. لا يتضمن أي تعديل على قاعدة البيانات.
