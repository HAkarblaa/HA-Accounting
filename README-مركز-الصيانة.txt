تحديث مركز الصيانة والاستبدال فقط

المحتويات: index.html و service-worker.js، وهما ملفا الاستبدال في جذر المشروع.

التثبيت: فك ضغط الحزمة واستبدل الملفين المناظرين في جذر مشروع HA-Accounting، ثم انشر التعديل. امسح ذاكرة الموقع/أعد تحميل الصفحة بعد النشر إذا بقيت النسخة القديمة ظاهرة.

يعيد هذا التعديل واجهة مركز الصيانة والاستبدال إلى مسار استقبال الأعطال ومتابعة الاستبدال: الوصولات متعددة القطع، الإرسال إلى بغداد، تسجيل البدائل المستلمة، تسليم القطع للزبون، البحث والطباعة والتصدير، مصروفات المركز والتقرير اليومي. وتظهر اختصارات خاصة بالمركز في لوحة التحكم.

صلاحيات هذا القسم تقتصر على لوحة التحكم ومركز الصيانة والمخزون والزبائن والمجهزون والتقارير والإعدادات. لا تظهر فيه صفحات التسوق مثل الكاشير وفواتير البيع والشراء. لا يحذف التعديل سجلات المركز المخزنة، ولا يغيّر إعدادات أو واجهات المعالجات أو الهندسة المعمارية أو الأسواق أو الورشة الصناعية.
