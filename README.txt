تحديث قسم المعالجات: إظهار الديون بالسالب

المحتويات:
- index.html
- service-worker.js

ارفع الملفين إلى جذر موقع HA-Accounting واستبدل النسختين الحاليتين، ثم حدّث الموقع.

يعرض هذا التحديث رصيد الدين المتبقي بإشارة سالبة ضمن:
- بطاقات ديون الزبائن والمجهزين والمستحقات المجدولة.
- صفحة الديون وفواتير البيع والشراء.
- كشف حساب الزبون أو المجهز.
- تقارير الديون والمستحقات والفواتير.
- الفاتورة المطبوعة.

الإشارة السالبة للعرض فقط؛ مبالغ الفواتير والدفعات في الحسابات تبقى كما هي حتى لا تتغير آلية التسديد.
كما يتضمن آخر تحديثي لوحة الهندسة وإمكانية تعديل طريقة الدفع لفواتير المعالجات.
