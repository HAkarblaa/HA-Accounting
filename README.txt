تحديث لوحة القسم اليمني
=======================

الملفات:
- yemen-section.js: لوحة الاختصارات التسعة، الطلبيات، ورشة الصناعة، العملاء والموردون، المخزون، المصروفات والإيرادات، وربط حركة البيع والشراء بالمخزون.
- yemen-section.css: تنسيق المربعات والشاشات على الهاتف والكمبيوتر.
- service-worker.js: تحديث نسخة التخزين المؤقت حتى تصل الملفات الجديدة للأجهزة.

طريقة التحديث:
1) ارفع الملفات الثلاثة إلى جذر مستودع HA-Accounting مع استبدال نظائرها.
2) انتظر نشر GitHub Pages، ثم أغلق التطبيق وافتحه أو سوِّ تحديثاً كاملاً للصفحة.

إصلاح اختيار «القسم اليمني» في إدارة الحسابات نُشر مباشرة على دالة الإدارة الخلفية (الإصدار 11). قاعدة البيانات تقبل الاختصاص بالفعل، ولا يحتاج هذا التحديث إلى SQL.

عزل البيانات:
كل سجلات هذا القسم محفوظة ضمن بيانات القسم اليمني فقط. الفواتير تضيف وتخصم الكميات من المخزون، وورشة الصناعة تخصم المادة الخام وتضيف المنتج المصنّع. هذه التعديلات لا تغيّر أقسام الموقع الأخرى.
