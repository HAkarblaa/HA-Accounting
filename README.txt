تعديل فاتورة المعالجات: تغيير طريقة الدفع

المحتويات:
- index.html
- service-worker.js

طريقة التثبيت:
ارفع الملفين إلى جذر موقع HA-Accounting واستبدل النسختين الحاليتين بهما، ثم افتح الموقع وحدّثه.

التعديل يضيف إلى نافذة تعديل فاتورة البيع والشراء:
- تغيير الدفع بين نقد أو آجل أو أقساط.
- تعديل المبلغ المدفوع، وإظهار المتبقي مباشرة.
- تحديد تاريخ استحقاق الآجل، أو تاريخ أول قسط وعدد الأشهر.
- إعادة جدولة المبلغ المتبقي عند اختيار الأقساط.
- تحديث سجل الدفعات وقناة الدفع عند تعديل المبلغ المدفوع.
- الحفاظ على حقول المواد والعملة وسعر الصرف والخصم والضريبة والتوصيل الموجودة.

ملاحظة: الفاتورة النقدية يلزم أن تكون مدفوعة بالكامل. إذا بقي مبلغ غير مدفوع، اختر آجل أو أقساط.
