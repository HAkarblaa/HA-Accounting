روابط الاتصال والواتساب لأرقام الزبائن والمجهزين في المعالجات

الملفات:
- index.html
- service-worker.js

في قائمة الزبائن والمجهزين يظهر لكل رقم مسجل زران:
- اتصال: يفتح تطبيق الهاتف للاتصال بالرقم.
- واتساب: يفتح محادثة واتساب للرقم، مع تحويل الرقم المحلي الذي يبدأ بصفر إلى مفتاح العراق 964.

لا يتغير رقم الجهة أو بياناتها المخزنة. يعمل الرابط عند فتح الموقع على جهاز يدعم الاتصال أو واتساب.

التطبيق: استبدل الملفين في جذر الموقع ثم أعد تحميله.
